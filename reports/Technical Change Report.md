## **📄 Технически отчет – Финализиране на ML inference модула**

### **1. Завършване на ML pipeline-a**

Всички основни компоненти бяха имплементирани:

| **Компонент**     | **Статус** | **Описание**                                                     |
| ----------------- | ---------- | ---------------------------------------------------------------- |
| model_loader.py   | ✔ Готово   | Зарежда модела и артефактите, кешира ги, добавя custom metric    |
| preprocessing.py  | ✔ Готово   | Енкодира категории, скалира числови стойности, подрежда фичъри   |
| predictor.py      | ✔ Готово   | Извършва inference през Keras модела                             |
| postprocessing.py | ✔ Готово   | Ограничаване на отрицателни стойности, връща крайно предсказание |
| inference.py      | ✔ Готово   | Комбинира всички стъпки в run_model_inference()                  |
